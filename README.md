For future STORMBOTS that use this as a sample code project, and for other FTC teams, hi. My name is Malaravan Vijayakumar, and I was the captain of 24457 Typhoon Stormbots.

The repository you see above contains the code for our robot. Use it as a good example of how to make good bots, but just so you know, this is not the code I ran at competition. I originally designed Melvin Pathing, which was my own autonomous library.

The code in front of you was made in parallel using only Pedro Pathing natively. Therefore, anyone can easily use this and build off of it.

Melvin Pathing was meant to be an autonomous program centered around my friends Jonah Ho, Shahir Rob, and Nathan MacFarlane and their interesting build/CAD styles. Melvin Pathing adapted to their non-conventional designs in order for me to utilize 100% of their effort.

There will never be another person who could recreate Jonah's building style or Nathan's way of CAD-ing (or I guess modeling, because it was in Blender), and therefore there will never be a person who will require Melvin Pathing again.

This README will remain as the global record of what Melvin Pathing was. Melvin Pathing was a program built using the magic of friendship.
